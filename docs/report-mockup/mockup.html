How to read this report

  • Call by rank. Phylum to species. A rank is called when the nearest reference genomes agree on it (vote consistency) and the input is similar enough to them (ANI). Higher ranks are easier than lower ones, so the ladder can stop part-way.
  • Vote consistency is the share of near-best references agreeing on the taxon, an evidence value, not a probability.
  • ANI here is containment ANI: the k = 21 sketch fraction of the input found in a reference, raised to 1/21.
  • Species labels follow the reference metadata. Where references disagree about a name (hybrids, species complexes) the genus is usually right and the species is withheld; the ANI cluster is the safer unit.
  • Thresholds are calibrated to about 95% precision on held-out genomes of the reference (known set). Genomes from a genus the reference lacks need the stricter novel set.
